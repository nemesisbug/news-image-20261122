# The World in One Image — Sunday 22 November 2026

make.fun bounty entry for **news-image-20261122**: sum up 22 November 2026's
world news in one image.

## The entry

`entry.png` (1024×1024, ~177 KB) is a newspaper front page for Sunday
22 November 2026, rendered at build time by `build_image.py` (Python 3,
Pillow, DejaVu fonts — all local, no network). `main.py` (stdlib only)
copies it to `$MAKEFUN_OUTPUT_DIR/entry.png` and verifies the copy
byte for byte. Both runs write identical bytes.
